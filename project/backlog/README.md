# Backlog

One file per work item, named `B-NNN-short-title.md`. `INDEX.md` is generated by
`python3 -I tools/check.py` and must not be edited by hand. The allowed values
for `milestone`, `priority`, `status` and `role` live in `project/process.toml`.

## Item format

```
---
id: B-001
title: Short imperative title
milestone: M0              # one of backlog.milestones in process.toml
priority: P0               # P0 now, P1 next, P2 later
status: ready              # idea | blocked | ready | in-progress | review | done | dropped
role: implementer          # a role from process.toml, or human
depends_on:                # comma-separated B-IDs, or empty
questions:                 # comma-separated Q-IDs that must be answered first, or empty
owner:                     # who holds it right now (agent run or person), or empty
updated: 2026-10-31
---

## Goal
What done looks like, in one paragraph.

## Acceptance
- [ ] Checkable statements. A reviewer ticks these.

## Notes
Links, context, things learned while doing it.
```

## Rules

- `ready` requires every `depends_on` item to be `done` and every linked question to be
  `answered`. `check.py` fails otherwise.
- `blocked` must have at least one unmet dependency or open question; otherwise it is
  `ready` or `idea`.
- `in-progress` and `review` must have an `owner`.
- Only Ed sets `dropped`.
- Touch `updated` on every edit, and add a journal row when the status changes.
- An implementer takes exactly one `ready` item at a time and never edits another
  item's file.
