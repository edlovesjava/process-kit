## Goal
The program manager reviews how the kit was built, from `project/activity.md`, the item
notes and `SITREP.md`, and writes `docs/process/review-m2-<date>.md`. The bootstrap was one
session doing every role (D-002), so the metrics will mostly measure that exception; the
review's value is the baseline and the first test of the template and the journal format.
