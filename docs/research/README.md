# Research notes

Findings the researcher writes when Ed asks a question that is not yet an ADR, a
question-register entry or a backlog item: comparisons, prior art, evaluations of an
external system. Each note separates what was verified (with a source and a date) from
what was recalled, gives options before a recommendation, and ends with proposals (items,
questions, ADR drafts) that Ed decides on. A note is a snapshot and is not edited once its
proposals have moved into `project/`; a later note supersedes it.

These notes are the kit's own records, like `docs/whitepaper.md`. They may name real
products, because prior art has names; the scaffold does not copy them.

Files: `<topic>-<yyyy-mm-dd>.md`.
